of every readable letter.

zarr-pyramid-audit is not an unrolling or ink-reading system. Its Grand Prize role is narrower and load-bearing: detect silent data defects, preserve evidence semantics, audit TIFXYZ surfaces, and make corrupted or unverified inputs fail loudly before they contaminate segmentation, training, rendering, or submission artifacts.

Why this matters for the Grand PrizeOfficial rules checked 2026-10-02; the Challenge page remains authoritative.

The 2027 Grand Prize requires reviewers to reproduce a complete pipeline, inspect TIFXYZ meshes, verify generated images, and trust that the submitted result is supported by the CT data. Silent all-zero or malformed pyramids can invalidate that chain without producing an obvious reader error.

Official Grand Prize requirements →

Scope boundary: a clean integrity audit does not prove correct sheet identity, full recto coverage, legible ink, or Grand Prize readiness. It proves only the checks actually run over the evidence available.

Controls that reduce reviewer risk

Unknown is not absent

Timeouts, permission failures, rate limits, and unsupported listings remain UNKNOWN; they cannot silently become a missing-data finding.

Report contract →

Headers are not content

The fast audit checks metadata and chunk presence; the sampled content probe separately decodes real voxels to test a different silent-corruption class.

Chunk probe evidence →

Fail closed before publish

zpa-gate converts severity policy into a non-zero CI exit code so known defect classes can block a publication step.

CI example →

Surface files get their own audit

TIFXYZ checks are separate from Zarr checks because a valid CT store does not imply a valid submitted surface.

Claims stay dated

Live-store findings are tied to dated artifacts so “still broken” is never presented as an eternal fact.

What a winning pipeline should do with this

Recommended integration point: run the integrity gate before expensive segmentation/training and again before freezing final inputs; run TIFXYZ audits before accepting meshes into the column/coverage manifest. Persist the exact report hashes beside the downstream artifact so a reviewer can reconstruct which data passed which checks.
